# Recurrence - Issue Tracker

This repo is just for reporting bugs and issues with the **Recurrence**
Minecraft mod (a Fabric mod). There's no source code here, this is bug
tracking only.

Get the mod itself here: [Modrinth link]

To report a bug, open a new [Issue](../../issues) and include:
- what you were doing when it happened
- Minecraft version + Fabric version
- any other mods you have installed
